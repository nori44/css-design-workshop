# 比較ワークシート

**「そう決めた理由」がいちばん大事な欄です。**

想定するチームは、実際の自分のチームでOK。一人で仕事をしている人は
「未来の自分＋AIとのチーム」や「外注パートナーと組むとき」を想定してください。
