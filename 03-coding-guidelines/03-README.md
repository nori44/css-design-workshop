# 実践③：コーディング規約づくり（25分）

実践①②で「決めてきたこと」（ファイル分割・レイヤー順・トークン運用）を、1つの文書に落とします。
AIに生成させた規約のたたき台2案を読み比べ、「自分のチームならどうするか」を決めて、規約に仕上げます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `drafts/draft-a.md` | たたき台A案（厳格運用寄り） |
| `drafts/draft-b.md` | たたき台B案（ゆるめ運用寄り） |
| `prompt.md` | `my-guidelines.md` をAIにレビューさせるプロンプト（持ち帰り用。2案を生成したプロンプトも参考として掲載） |
| `worksheet.md` | 5つの論点の比較ワークシート |
| `template.md` | 規約テンプレート（これをコピーして自分の規約を作る） |

## 手順

### 1. たたき台2案を読む（5分）

`draft-a.md` と `draft-b.md` をざっと読む。
同じプロンプトの「厳しさ」指定だけ変えて生成したものです。
**どちらが正解、はありません。** チームの人数・スキル・案件の寿命で最適解が変わります。

### 2. ワークシートで比較する（10分）

`worksheet.md` の5つの論点について、A寄り／B寄り／独自 を決め、**理由を書く**。
理由が今日いちばん大事な成果物です。「なぜこの書き方？」に答えるのが規約なので。

### 3. 自分の規約を作る（8分）

`template.md` をコピーして `my-guidelines.md` を作り、ワークシートの決定を書き込む。
全項目埋まらなくてOK。決まったところまでで「v0.1」です。

### 4. 共有（2分）

いちばん迷った論点と、その結論をチャットで共有してください。
チームによって結論が割れるのを見るのも、今日の学びの一部です。

## 持ち帰り

`prompt.md` は、今日作った `my-guidelines.md` をAIにレビューしてもらうためのプロンプトです。
`{ }` を自分のチームの情報に、`{my-guidelines.md の内容}` を実際の中身に書き換えて投げると、
未決事項の埋め方や矛盾点の指摘をもらえます。1回で終わらせず、直しては投げるを繰り返すのがコツです。
（ゼロから新しいプロジェクトの規約を作りたい場合の生成プロンプトも、`prompt.md` の後半に参考として載せています）
